## Codebase Patterns

### bun run validate needs extra Node heap on this runner
- **Where**: root `package.json` `validate` script (eslint)
- **Pattern**: First `bun run validate` OOM'd ESLint (`FATAL ERROR: Reached heap limit`, ~4GB). Re-run with `NODE_OPTIONS=--max-old-space-size=8192 bun run validate`. That env is a runner workaround, not a committed script change.
- **Example**: `NODE_OPTIONS=--max-old-space-size=8192 bun run validate`

### Pre-existing prettier mockup drift blocked validate
- **Where**: `_bmad-output/specs/spec-workflow-run-view-hitl/ux-mockup/{app.js,console-app.js,styles.css}`
- **Pattern**: `bun run format:check` failed on these three files on a clean stash (not in the spike File Map). UNBLOCK PROTOCOL: stash story work, format only those paths, `chore(unblock):` commit, then restore. Fingerprint is prettier warn on those three paths.
- **Example**: commit `97442681`

### Ralph YAML effort vs contract tests blocked validate
- **Where**: `packages/workflows/src/dag-executor.test.ts:6901`, `packages/workflows/src/loader.test.ts`
- **Pattern**: Native Ralph YAML `ralph-loop-run` is `effort: high` / `omp` / `xai-oauth/grok-4.5`; tests expected `xhigh`. Same fingerprint on clean base. UNBLOCK: update tests to match YAML, not YAML to match tests. Commit `chore(unblock):` with zero story files.
- **Example**: commit `ae532e0e`

### Prettier eats unquoted markdown underscores
- **Where**: `_bmad-output/implementation-artifacts/workflow-run-view-hitl/6-1-askhuman-resume-spike.md`
- **Pattern**: lint-staged prettier converts `mcp__archon__AskHuman` to `mcp**archon**AskHuman`. Wrap the tool name in backticks before commit so the exact AD-6 CONFIRM statement keeps the custom MCP id.
- **Example**: `` `mcp__archon__AskHuman` ``

### Isolated 0.3.261 comparison must not touch the pin
- **Where**: `_bmad-output/implementation-artifacts/workflow-run-view-hitl/evidence/6-1-claude-0.3.261.json`
- **Pattern**: Copy the self-contained harness into `mktemp -d`, `bun add --exact @anthropic-ai/claude-agent-sdk@0.3.261 zod@4.4.3`, run with `EXPECTED_CLAUDE_SDK_VERSION=0.3.261`, redirect stdout only, then `rm -rf` only after a non-root safety check. A differing 0.3.261 protocol is comparison evidence; keep exact 0.3.209.
- **Example**: `0.3.209 host-abort-new-user-message` vs `0.3.261 tool-deferred-reissue`

### Claude 0.3.209 evidence is a redacted live JSON document
- **Where**: `_bmad-output/implementation-artifacts/workflow-run-view-hitl/evidence/6-1-claude-0.3.209.json`
- **Pattern**: Run `bun run spike:askhuman:claude` with CLAUDE_SPIKE_MODELS=sonnet,opus and EXPECTED_CLAUDE_SDK_VERSION=0.3.209. Redirect stdout only. Validate with the plan jq expression plus the rg secrecy scan. Do not upgrade the pin when defer is incomplete.
- **Example**: `"protocol": "host-abort-new-user-message"`

### Pi durable resume uses real lifecycle plus faux transport
- **Where**: `packages/providers/src/community/pi/askhuman-resume.characterization.test.ts`
- **Pattern**: Prove AskHuman continue with real SessionManager / AgentSession / session.agent.continue(). Replace only the model transport via registerFauxProvider. Cleanup must prefix-check the temp dir before rmSync.
- **Example**: `await second.agent.continue()`

### Live Claude harness is copyable and gated
- **Where**: `packages/providers/src/claude/askhuman-resume-spike.ts`, `packages/providers/package.json`
- **Pattern**: Keep the file self-contained (SDK + zod + Node built-ins). Guard live `query()` with `import.meta.main`. Expose `spike:askhuman:claude` only as a manual script. Host-abort uses one shared handler counter snapshotted after the first query.
- **Example**: `if (import.meta.main) { await main(); }`

### Fail-closed Claude classifier is diagnostic-only
- **Where**: `packages/providers/src/claude/askhuman-resume-spike.ts`
- **Pattern**: Keep this module out of production exports and SDK types. Decision order is load-bearing: `requiresActionSeen` / `failureCategory` → same-id defer round trip → host abort → `inconclusive`. Prefer host abort first and the defer-preference test fails.
- **Example**: `if (deferredProved) return 'tool-deferred-reissue';`

### Exact Claude SDK pin for the AskHuman spike
- **Where**: `package.json:76`, `packages/providers/package.json:38`, `bun.lock` workspace specs
- **Pattern**: Spike evidence requires the literal version `0.3.209` (no caret). `bun install --lockfile-only` updates only the two workspace specs; the resolved package stays `0.3.209`. Do not upgrade to `0.3.261` on this branch.
- **Example**: `"@anthropic-ai/claude-agent-sdk": "0.3.209"`

### Provider test isolation
- **Where**: `packages/providers/package.json:34`
- **Pattern**: Provider tests must run as separate `bun test <file>` invocations in the package `test` script. Do not run unscoped `bun test` from the repo root.
