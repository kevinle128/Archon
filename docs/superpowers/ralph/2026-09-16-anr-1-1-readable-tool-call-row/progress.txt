## Codebase Patterns

### Tool-item context vs DAG-node context
- **Where**: `packages/web/src/lib/agent-history.ts` vs `NodeInspector.tsx` / `WorkflowCanvas.tsx`
- **Pattern**: After removing tool-item `context` / `toolContext` / `TOOL_CONTEXT_KEYS`, `rg '\.context\b'` still matches workflow YAML `context: 'fresh'` on DAG nodes. Those are not production readers of `AgentHistoryItem.context`.
- **Example**: `value={node.context ?? ''}` is session inheritance, not a tool row.

### Console isolation allowlist must include new @/lib imports
- **Where**: `packages/web/src/experiments/console/console-isolation.test.ts` approved set
- **Pattern**: Console run-room files may import `@/lib/agent-history` and `@/lib/tool-presentation`. Adding a new `@/lib/` import in ConsoleAgentHistoryList requires adding that spec to the approved set or isolation fails.
- **Example**: `'@/lib/tool-presentation'`

### Console live-transition tests render the list, not the room
- **Where**: `packages/web/src/experiments/console/components/ConsoleNodeRoom.test.tsx`
- **Pattern**: Build running/failed items with `buildAgentHistory()` wire rows (`tool_phase` call/result). Render `ConsoleAgentHistoryList` directly so hook refs survive the same `toolUseId`.
- **Example**: `createElement(consoleAgentHistoryList.ConsoleAgentHistoryList, { items, ... })`

### Console running glyph uses --running
- **Where**: `packages/web/src/experiments/console/components/inspect/ConsoleAgentHistoryList.tsx` `glyphColor()`
- **Pattern**: Same disclosure markup as Legacy except `running` → `var(--running)` and keep `var(--rv-tool-card-border, 1px solid var(--border))`. Duplicate `useToolDisclosure` locally (AD-12).
- **Example**: `case 'running': return 'var(--running)';`

### Legacy tool disclosure is native details, not controlled open state
- **Where**: `packages/web/src/components/workflows/NodeRoom.tsx` `useToolDisclosure()` / `ToolHistory()`
- **Pattern**: `initialOpenRef` captures `initialToolExpanded(outcome)` once. `open={initialOpen || undefined}` is only the initial attribute. `markTouched` on summary click lets reader choice outrank the failed auto-open effect. Duplicate this hook locally in Console (AD-12); do not import it from Legacy.
- **Example**: running → failed with untouchedRef false sets `details.open = true`; two summary clicks then failed keeps it closed

### Inspect summary text, not whole-card markup
- **Where**: `packages/web/src/components/workflows/NodeRoom.test.tsx` `firstToolSummaryMarkup()`
- **Pattern**: Closed native `<details>` still contains Input/Output JSON in the DOM. Extract the first `<summary data-testid="tool-summary">` fragment, then `visibleText()`, before asserting no `{` / `[` / `"`.
- **Example**: `visibleText(firstToolSummaryMarkup(markup))`

### Happy-dom live transitions follow NodeRoomHeader
- **Where**: `packages/web/src/components/workflows/NodeRoom.test.tsx` live-transition describe
- **Pattern**: `process.env.NODE_ENV = 'development'` plus `installHappyDom` / `createRoot` / `act`. Re-render the same `item.id` so hook refs survive. Query `details[data-tool-id]` `.open`.
- **Example**: `NODE_ENV=development bun test --cwd packages/web src/components/workflows/NodeRoom.test.tsx`



### Interrupted fold is a final pass
- **Where**: `packages/web/src/lib/agent-history.ts` `foldInterruptedLifecycle()`
- **Pattern**: After projecting items, walk once. A lifecycle with `state === 'interrupted'` whose previous emitted item is a tool is omitted and that tool's `outcome` becomes `'interrupted'`. Non-interrupted and orphan interrupted rows stay.
- **Example**: `call + result + statusRow('interrupted')` → one tool with `outcome: 'interrupted'`

### Shared exit code drives outcome and badge
- **Where**: `packages/web/src/lib/agent-history.ts` `resolveExitCode()`
- **Pattern**: Result metadata, then call metadata, then `card.exitCode`. `deriveOutcome()` and `toToolItem()` both call this helper so a non-zero exit cannot succeed while the badge disagrees.
- **Example**: `{ tool_phase: 'result', exit_code: 1 }` → `outcome: 'failed'`, `exitCode: 1`, sticky `exit 1`

### Badge order is payload, exit, output-state, duration
- **Where**: `packages/web/src/lib/agent-history.ts` `toolRowView()`
- **Pattern**: Payload facts first, then non-zero finite `exit N`, then truncated/missing/unknown marker, then duration. Only duration is `droppable`.
- **Example**: `['javascript', 'exit 1', 'truncated', '1.5s']`

### MCP names resolve before alias/duck-type
- **Where**: `packages/web/src/lib/tool-presentation.ts` `mcpPresentation()`
- **Pattern**: Match `/^mcp__(.+?)__(.+)$/` first. Chip label is `server · tool` when ≤ 24 chars, otherwise the family name `generic`. Headline keeps the formatted pair even when the chip falls back.
- **Example**: `mcp__server__tool` → `{ family: 'generic', label: 'server · tool' }`

### Generic scalars via own data descriptors
- **Where**: `packages/web/src/lib/tool-presentation.ts` `genericHeadline()`
- **Pattern**: Walk `Object.keys` and read `Object.getOwnPropertyDescriptor(record, key).value`. Skip nested objects/arrays, non-finite numbers, and accessors. Never `JSON.stringify` or `for…in`. Cap at 3 pairs; truncate values at 80 + `…`.
- **Example**: `{ a: 1, nested: { x: 1 }, b: 'two', list: [1, 2], c: true, d: 'ignored' }` → `a: 1 · b: two · c: true`

### Chip sent-name rule is all-or-nothing
- **Where**: `packages/web/src/lib/tool-presentation.ts` `chipLabelFor()`
- **Pattern**: Keep the sent name only when `/^\S+$/` and `length <= 24`. Never truncate a chip; fall back to the family id. `chipAriaLabel` is `${label}, ${family} tool` when they differ, else `${family} tool`.
- **Example**: `'npm test'` → label `shell`, aria `shell tool`

### React-free web lib resolver
- **Where**: `packages/web/src/lib/tool-presentation.ts`
- **Pattern**: Shared presentation lives in `packages/web/src/lib/` with no React and no `@archon/*` imports. Tests sit beside the module as `*.test.ts` and run via `bun test --cwd packages/web src/lib/<file>.test.ts`. ESLint ignores `**/*.test.ts`; lint the production file only.
- **Example**: `export function toolPresentation(input: ToolPresentationInput): ToolPresentation`

### Exact normalized alias match, never substring
- **Where**: `packages/web/src/lib/tool-presentation.ts` `normalizeToolName` / `FAMILY_ALIASES`
- **Pattern**: Case-fold and strip `_`/`-` only (spaces stay). Match the full normalized token against the alias list. `search_replace` → `searchreplace` hits file, not search.
- **Example**: `name.toLowerCase().replaceAll(/[_-]/g, '')`

### Malformed input is generic before alias resolution
- **Where**: `packages/web/src/lib/tool-presentation.ts` `toolPresentation()`
- **Pattern**: Invalid name or non-`undefined` non-plain-object input (null, array, primitive) returns generic without throwing. Missing input and `{}` are the Codex name-only shell path, after alias/key resolution.
