Inherited, and one correction

HITL AD-3 — the transcript table is the only source

The rooms read remote_agent_workflow_node_messages ordered by seq, and nothing else. Track A adds no source and no column. That is precisely what makes it retroactive: every run already stored gets the new transcript with no migration and no re-run.

HITL AD-4 — Console isolation

Console must not import @/components, @/contexts, @/hooks, @/routes, @/stores, react-query, or @/lib/api functions. Type-only api.generated.d.ts is allowed — a different module path, outside the ban.

The correction this spine carries

The parent also calls lib/run-graph “the one sanctioned console isolation exception”. That clause is stale. The enforced rule is the prohibition list; @/lib/ outside @/lib/api was never restricted, and Console imports thirteen @/lib/ paths today.

The prohibition list stands unchanged — only the exception-counting sentence is wrong, and amending it belongs to the parent spine’s own update, not to a local override here.

Deliberately not decided

Deferred

  • Memoizing the resolver at the call sites. AD-8 carries the revisit condition: a node reaching the low hundreds of rows while live-streaming.
  • A transcript-scoped error boundary. AD-3 makes the core unable to trigger one.
  • Adopting the presenter in chat’s tool card. The input type is structural so it can — a separate slice, and a spec non-goal today.
  • Deleting the Legacy shell. Scheduled elsewhere. AD-1 is what makes it a deletion rather than a migration.
  • Virtualising very long transcripts. No evidence a node needs it; it would be a shell decision and the core would not change.

  • The glyph for a successful row with no output. EXPERIENCE.md:91 derived the glyph from the outcome and in the same cell said – covers a missing output. AD-13 pinned outcome alone, and that cell was corrected on 2026-09-12 — output state is a badge.
  • The Codex command prefix. The contract’s Tier 3 and EXPERIENCE.md:93 disagreed across 21.5% of all rows. AD-15 put the strip in the core, and Tier 3 now carries it.
