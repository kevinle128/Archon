- (constraint) CORRECTION to what was told the user when that option was offered: structuredPatch does NOT hand back the adapter's input unchanged. Verified against the published jsdiff docs — StructuredPatchHunk is {oldStart, oldLines, newStart, newLines, lines: string[]} where lines are prefix-encoded strings (' ctx', '-del', '+ins', and a '\\ No newline at end of file' marker).
