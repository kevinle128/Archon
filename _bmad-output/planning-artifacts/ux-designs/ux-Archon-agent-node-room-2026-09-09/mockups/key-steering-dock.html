Steering dock — the agent's states inside a running node

Console shown at a 300px crop of the node panel. Legacy differs in :root and in one place only: its send control is the filled shadcn Button the ask card already uses, where Console's is bordered. Anatomy, order and wording are identical on both. The dock is a sibling of the transcript's scroller, never a child of it — so it cannot cover the last row, which on a running node is the row being watched. The node pill stays running across every state below except the terminal fail: steering acts on the agent, never the node lifecycle.

The owner-ratified bound. While idle-after-interrupt the dock waits (Send now). If nothing is sent, the engine — the in-process owner, which can tell idle-after-interrupt from a crash — fails the node after 30 minutes: never a wait-forever, never a quiet finish on partial output. The in-memory queue dies with the run; anything still sent but unmatched returns read-only as Never sent. Resuming re-runs the node with a fresh session — the interrupted context is gone.

Three things separate the operator from the model, and none is a hue: the operator label with the sender's name (the operator_user_id, so a multi-user install attributes each message), and full-strength text against the model's secondary saying it again. The badge reads sent here and stays that way — only Claude echoes back the id we stamp, so on every other provider delivered is never claimed.

What the dock refuses to do

RefusedWhy
a send that stops the nodeA send is never a node-stop — stopping the whole node is the separate Cancel button. Stop interrupts the agent's current turn (every provider can be interrupted), which is a distinct act; a send control that silently stopped the agent would lie about what it does.
per-item send while generatingThere is nothing an individual message could do but wait. Same lie, one row down.
optimistic flip to idle before the interrupt landsThe interrupt is sub-second but not zero. The interface must not fake being done before the agent acknowledges — a flip that runs ahead of the ack is wrong for exactly as long as it leads.
a delivered badge without an echoCorrelation is by id alone. Text and timestamps mis-attribute silently when messages merge into one turn.
an empty draft boxA panel that is always there stops being a signal.
Enter to sendA stray keystroke must not be able to reach a running agent.
