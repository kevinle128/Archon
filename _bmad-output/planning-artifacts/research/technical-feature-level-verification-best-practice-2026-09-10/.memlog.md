- (claim) ref=[15] status=verified class=versions pub=2026-09 — GitHub required-check evaluation accepts success, skipped, and neutral; an always-running fail-closed aggregator is an Archon design synthesis.

- (claim) ref=[17] status=verified class=versions pub=2026-09 — Playwright documents UI mutation followed by real API validation of the server-side postcondition.
- (claim) ref=[18] status=verified class=versions pub=2026-09 — Fulfilling a mocked route prevents the real API request; narrowing the proof boundary is an architectural inference.
- (claim) ref=[19] status=verified class=versions pub=2026-09 — BrowserContext isolates browser-profile state; application server-state isolation remains a separate harness responsibility.
- (claim) ref=[21] status=verified class=versions pub=2026-09 — failOnFlakyTests makes a retry-only flaky Playwright result exit as failed.
