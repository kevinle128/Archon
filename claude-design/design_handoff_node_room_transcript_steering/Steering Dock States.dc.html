The dock is a sibling of the transcript's scroller, never a child of it — so it cannot cover the last row, which on a running node is the row being watched. The node pill stays running across every state below except the terminal fail: steering acts on the agent, never the node lifecycle.

What the dock refuses to do

Refused Why
a send that stops the turn Queue and Send now use their declared delivery path. A send control that silently invoked Stop would lie about what it does.
Send now without capability Per-item Send now appears only for providers with verified soft injection.
optimistic flip to idle before the interrupt lands The interrupt is sub-second but not zero. The interface must not fake being done before the agent acknowledges — a flip that runs ahead of the ack is wrong for exactly as long as it leads.
a delivered badge without an echo Correlation is by id alone. Text and timestamps mis-attribute silently when messages merge into one turn.
an empty draft box A panel that is always there stops being a signal.
Enter to send A stray keystroke must not be able to reach a running agent.
