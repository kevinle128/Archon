## Codebase Patterns

### happy-dom focus assertions in bun:test
- **Where**: `packages/web/src/components/workflows/ComposerDock.test.tsx`
- **Pattern**: `expect(win.document.activeElement).toBe(el)` fails typecheck — bun:test overloads `toBe` for `HTMLElement | SVGElement` only. Use the file's convention: `expect((win.document.activeElement as unknown) === el).toBe(true)`. `.not.toBe(win.document.body)` is fine (body is HTMLElement).
- **Example**: `expect((win.document.activeElement as unknown) === field()).toBe(true);`

### Steering queue lifecycle (process-local)
- **Where**: `packages/workflows/src/steering-registry.ts`
- **Pattern**: `NodeSteeringHandle` holds `pending[]` + `accepted` id-memory + `phase: live|parked|closed`. Mutators are synchronous; `closeIfEmpty()` is the executor's only teardown gate — handle helpers must never auto-close or auto-resume.
- **Example**: `withdraw()` mirrors `drain()` — splice pending only, never touch `accepted`, never change `phase`.

### Steering API routes in api.ts
- **Where**: `packages/server/src/routes/api.ts` (send route ~line 5200s; withdraw ~5322)
- **Pattern**: method-scoped auth middleware on the colon-param path BEFORE `registerOpenApiRoute(...)` so gated-401 wins over OpenAPI param validation; bodyless methods take no `request.body` in the route config; handler order is auth → run load → events+projection+handle → refusal ladder → run re-read → post-await `handle.snapshot().phase` recheck → synchronous mutation → narrow completion log (never message content) → nested `{success:false,error:{code,message}}` errors only.
- **Example**: `registerOpenApiRoute(withdrawWorkflowNodeRoute, handler, steeringValidationErrorHook)`

### api.generated.d.ts regeneration
- **Where**: `packages/web/src/lib/api.generated.d.ts`
- **Pattern**: start THIS worktree's server on a verified-free alternate `PORT` (3090 may belong to another session — `lsof -i :<port>` and `lsof -p <pid>` to check cwd), confirm `/api/openapi.json` contains the new path+schema, run `openapi-typescript http://localhost:<port>/api/openapi.json -o <file>`, review diff is purely additive, then kill ONLY the recorded PID.
