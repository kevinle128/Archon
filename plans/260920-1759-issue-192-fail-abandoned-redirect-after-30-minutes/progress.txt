## Codebase Patterns

### E2E idleAwaitMs worker option (Story 2.12)
- **Where**: `e2e/lib/playwright/suite.ts`, `archon-runtime.ts`
- **Pattern**: Worker-scoped Playwright option `idleAwaitMs` feeds `ARCHON_E2E_STEERING_IDLE_AWAIT_MS` via `serverEnv` on the server spawn only (CLI env unchanged). Spec uses `test.use({ idleAwaitMs: 8_000 })`; other specs omit and keep 30 min.
- **Example**: `createArchonRuntime(workerIndex, { serverEnv: { ARCHON_E2E_STEERING_IDLE_AWAIT_MS: '8000' } })`


### Keepalive coalescer + idle disclosure (Story 2.12)
- **Where**: `packages/web/src/lib/steering-dock.ts` (`createKeepaliveCoalescer`, `neverSentDisclosure`, constants); docks in `ComposerDock.tsx` / `ConsoleComposerDock.tsx`
- **Pattern**: Leading-plus-trailing coalescer with injected clock/scheduler. First touch sends immediately; interior activity schedules one trailing at window boundary. One coalescer per idle attempt — dispose on leave idle, attempt-key change, unmount, and Send now. Docks touch on textarea focus + non-submit keydown only while idle. Disclosure renders Stop text then exact 30-min line. Finished band uses `neverSentDisclosure(idleAwaitExpired)`.
- **Example**: `createKeepaliveCoalescer({ send, now, setTimer, clearTimer })`; `neverSentDisclosure(true) === STEERING_NEVER_SENT_IDLE_EXPIRED_DISCLOSURE`

### idleAwaitExpired evidence (Story 2.12)
- **Where**: `packages/web/src/lib/execution-room-model.ts` (`hasIdleAwaitExpiredEvidence`); computed in `LegacyGraphLogsPane` / `ConsoleInspectPane` beside `nodeTerminal`
- **Pattern**: Filter selected node rows; require all terminal; pick latest by retry_epoch → started_at??ended_at??'' → array index; true only when latest is failed with exact IDLE_AWAIT_EXPIRED_ERROR mirror. Evaluate actual selected id so `grp.body` vs `grp` never cross.
- **Example**: `hasIdleAwaitExpiredEvidence(nodeExecutions, selectedNodeId)`

### Executor expired wake branches (Story 2.12)
- **Where**: `packages/workflows/src/dag-executor.ts` (`executeNodeInternal`, `executeLoopNode`)
- **Pattern**: After `send_now`, branch on `wake.kind === 'expired'`. Prompt path throws `Error(IDLE_AWAIT_EXPIRED_ERROR)` into the existing generic catch (sole finalizer — do not abort `nodeAbortController`). Loop path returns `failLoopIteration(exact, extras, exact)` so the outer node error is not wrapped. Loop `terminated` closes the handle synchronously before status/message awaits so a losing timer cannot fire mid-await.
- **Example**: `if (wake.kind === 'expired') { getLog().warn(...); throw new Error(IDLE_AWAIT_EXPIRED_ERROR); }`

### Deterministic Cancel-vs-expiry race in executor tests
- **Where**: `packages/workflows/src/dag-executor.test.ts` (T2.5 / T2.8)
- **Pattern**: Hold the first `getWorkflowRunStatus` that observes `idle-after-interrupt` on a deferred gate; `awaitIdle` then spin microtasks until the hold is set; release as `cancelled`; call `expireIdleForTests()` after the run to prove stale expiry is inert. No wall-clock `CANCEL_CHECK_INTERVAL_MS` waits.
- **Example**: `idlePollHeld = true; await idlePollGate; return 'cancelled'`

### Idle-await inactivity timer (Story 2.12)
- **Where**: `packages/workflows/src/steering-registry.ts`
- **Pattern**: One process-local timer per idle waiter. `enterIdle` installs the waiter then arms; `keepalive()` re-arms without resolving; `send_now`/`seal()` cancel before resolve. Expiry resolves `{ kind: 'expired' }` without changing phase/sub-state/queue — handle stays live/idle for failure teardown + queue reconciliation. Generation counter + cancel make stale callbacks inert.
- **Example**: `createSteeringRegistry({ idleAwaitInactivityMs, scheduleIdleExpiry })` for tests; production uses `scheduleIdleExpiryWithTimeout` + `resolveIdleAwaitInactivityMs(process.env)`.

### Manual idle scheduler in tests
- **Where**: `packages/workflows/src/steering-registry.test.ts`
- **Pattern**: Inject `ScheduleIdleExpiry` that records jobs with `cancelled` flags; `fire(job)` always invokes the callback so generation guards are proven. Never fake global clocks or sleep.
- **Example**: `const scheduler = createManualScheduler(); createSteeringRegistry({ scheduleIdleExpiry: scheduler.schedule })`

### Timer unref convention
- **Where**: production `scheduleIdleExpiryWithTimeout` and existing server timers
- **Pattern**: `const t = timer as unknown as { unref?: () => void }; if (typeof t.unref === 'function') t.unref();`
- **Example**: Same guarded cast used by dashboard-event-poller / workflow-events dispatcher.

### Bodyless keepalive route ladder (Story 2.12)
- **Where**: `packages/server/src/routes/api.ts` (keepalive route + handler)
- **Pattern**: Mirror interrupt guard ladder exactly (auth → 404 → 409 terminal/closed → 422 missing/parked → final run re-read → synchronous `handle.keepalive()`). Public body is always `{ success: true }` — private `rearmed`/`not_idle` is not exposed. Parked must be checked before keepalive because keepalive returns `not_idle` for parked (would incorrectly 200). Error log event: `api.workflow_node_keepalive_failed`.
- **Example**: `handle.keepalive(); return c.json({ success: true as const }, 200);`

### keepaliveNode client (no body / no content-type)
- **Where**: `packages/web/src/lib/api.ts`
- **Pattern**: Same encoding style as interruptNode; `fetchJSON(url, { method: 'POST' })` with no body and no headers so no synthetic JSON content-type; failures via `toSteeringRequestError` without auto-retry.
- **Example**: `return await fetchJSON<KeepaliveWorkflowNodeResponse>(url, { method: 'POST' });`
