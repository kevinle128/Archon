## Codebase Patterns

### Authority docs for Story 2.10
- **Where**: readable-transcript `ARCHITECTURE-SPINE.md` AD-16; UX `DESIGN.md` Finished-iteration dock; `EXPERIENCE.md` Execution vs Jump-to + dock state row
- **Pattern**: B1 = Execution selection entry + mutation-only ban + shared GET queue band; B2 = one flex row, disclosure wraps, Go ≥32px, band below. Headless adoption recorded in plan Validation Log.
- **Example**: AD-16 rule + DESIGN finished-iteration dock anatomy

### Finished-iteration shared core
- **Where**: `packages/web/src/lib/execution-room-model.ts` (`resolveFinishedIterationView`); `steering-dock.ts` (`finished-iteration` mode + optional `onError`); both `build-log-rows.ts` occurrence mappers
- **Pattern**: Preserve full `loopAncestry` on occurrence selections; resolver proves same-lineage live candidate (retry/route/prefix/final-node) and fails closed; mode trusts a non-null descriptor and never mutates; poll `onError` is optional and fires once before retry/stop
- **Example**: `resolveFinishedIterationView({ rows, selected, nodeStatus: 'running', live: true })` → `{ liveRowId, liveIteration }` or `null`

### Legacy finished-iteration dock wiring
- **Where**: `LegacyGraphLogsPane.tsx` (descriptor once); `NodeTranscriptPane.tsx` (consume-once `pendingGoTargetRef`); `ComposerDock.tsx` (finished branch)
- **Pattern**: Descriptor only when `onSelectExecution` exists; Go stores `{fromRowId,toRowId}` then calls existing selection; clear pending before focus — field / Go / scroller; finished poll 422 is inline alert (not detached mode)
- **Example**: `finishedIteration={resolveFinishedIterationView(...)}` + `onSelectLiveRow={onSelectExecution}`

### Console finished-iteration dock wiring
- **Where**: `ConsoleInspectPane.tsx` (descriptor once via `isInspectRunLive`); `ConsoleNodeRoom.tsx` (consume-once `pendingGoTargetRef`); `ConsoleComposerDock.tsx` (finished branch)
- **Pattern**: Parallel thin renderer of Legacy — same mode/poll/focus semantics, Console focus-ring classes (`outline-accent-bright!`); no Legacy imports; gate Go on `onSelectRow`
- **Example**: `finishedIteration={resolveFinishedIterationView({ rows: logEntries.map(e => e.row), ... })}` + room-owned focus handoff
