## Codebase Patterns

### Process-singleton module (event-emitter pattern)
- **Where**: `packages/workflows/src/event-emitter.ts:361-375`, mirrored in `steering-registry.ts`
- **Pattern**: module-level `let instance: T | null = null`; `getX()` lazily constructs; separate `createX()` returns isolated instances for tests (never shares singleton state); reset via `clearForTests()`/`resetX()`
- **Example**: `getSteeringRegistry()` (prod) vs `createSteeringRegistry()` (tests)

### Package exports + test chain (packages/workflows)
- **Where**: `packages/workflows/package.json`
- **Pattern**: every importable module gets an explicit `"./name": "./src/name.ts"` entry in `exports`; the package `test` script is an explicit `&&`-chained list of `bun test <file>` invocations — new test files MUST be appended or `bun run validate` silently skips them
- **Gotcha**: `bun --filter @archon/workflows` does NOT match — run `bun run type-check`/`bun test` from inside `packages/workflows/` instead

### Lint scope
- `*.test.ts` files are in the eslint ignore list — passing a test file explicitly to eslint emits a "file ignored" warning that fails `--max-warnings 0`; use `--no-warn-ignored` or lint only source files

### OpenAPI type generation without a port
- **Where**: `packages/web/package.json` `generate:types` (hardcodes `http://localhost:3090`), `registerApiRoutes` in `packages/server/src/routes/api.ts`
- **Pattern**: when 3090 is owned by ANOTHER workspace's server, do NOT hit it (stale types). `registerApiRoutes(app, {} as WebAdapter, {} as ConversationLockManager)` on a bare `new OpenAPIHono({ defaultHook: validationErrorHook })` registers every route — handlers capture deps lazily, nothing connects at registration. `await app.request('/api/openapi.json')` dumps the doc; `openapi-typescript <file>` accepts file paths, not just URLs. Script must live inside `packages/server/` (Bun resolves imports relative to the FILE, not cwd) — e.g. `dump-openapi.tmp.ts`, delete after
- **Gotcha**: `startServer()` picks a RANDOM port when 3090 is taken (`opts.port ?? getPort()`) — a `dev:server` boot under collision silently binds elsewhere AND the hardcoded `generate:types` URL still hits the wrong server

### Hono malformed-JSON vs route-scoped validation hooks
- **Where**: `packages/server/src/routes/api.ts` send-route middleware
- **Pattern**: `@hono/zod-openapi`'s json validator throws `HTTPException` inside compose BEFORE a route-scoped `validationErrorHook` runs; `try/catch` around `await next()` cannot intercept it (compose catches at the middleware level). Pre-parse `c.req.json()` in `app.use` middleware — Hono caches the raw body so the downstream validator re-reads it unchanged; malformed → map directly to the desired error shape

### Git
- Pre-commit runs lint-staged (eslint --fix + prettier on staged files) — works fine, no bypass needed
- `git commit -m "$(cat <<'EOF' ... EOF)"` heredoc broke in this shell; multiple `-m` flags worked
