## Codebase Patterns

### react-diff-view v3.3.3 unified-mode DOM contract
- **Where**: `packages/web/src/components/workflows/NodeRoom.tsx` + `.../ConsoleAgentHistoryList.tsx` InlineDiff, `packages/web/src/index.css` `.tool-diff` block
- **Pattern**: unified mode always emits `<colgroup><col class="diff-gutter-col"/><col class="diff-gutter-col"/><col/></colgroup>` and two `.diff-gutter` cells per `.diff-line` row — one visible gutter needs BOTH `col.diff-gutter-col:nth-child(2)` and `.diff-line > .diff-gutter:nth-child(2)` hidden plus a `renderGutter` that returns `null` for `side === 'new'`. `Decoration` renders `<tbody class="diff-decoration"><tr><td colSpan="3" class="diff-decoration-content">` — assert `tbody.diff-decoration`, never `/diff-decoration/` (matches `diff-decoration-content` too), and React SSR serializes the attribute camelCase `colSpan="3"`. For insert lines `renderDefault()` yields '' so the visible number needs `computeNewLineNumber(change)`; delete/normal use `renderDefault()`.
- **Example**: `const number = change.type === 'insert' ? computeNewLineNumber(change) : renderDefault();`


### Injecting control characters into test fixtures safely
- **Where**: `packages/web/src/lib/diff-hunks.test.ts` display-safety block, `packages/web/src/lib/diff-hunks.ts:33`
- **Pattern**: never type literal U+2028/U+2029/C0 chars into source — editors/tools mangle or double-escape them, and JS regex `.` never matches U+2028/U+2029 so `replace()` silently no-ops on lines containing them. Write `'\u{XXXX}'` escape syntax in the file, and edit by line index or `[\s\S]` patterns.
- **Example**: `const hostile = ['bad', '\u{2028}', '\u{001B}[31m'].join('')` — real chars at runtime, pure ASCII in the file.

### Adding a dep without lockfile drift
- **Where**: `bun.lock`
- **Pattern**: `bun install` opportunistically re-resolves floating ranges (it unified `@tanstack/react-virtual` 3.13.22→3.14.10 here). For a minimal story diff, hand-revert the unrelated hunks back to HEAD content — nested-package entries restore at their sorted key positions — then verify with `bun install --frozen-lockfile` (exits clean = self-consistent graph).
- **Example**: adding `"diff": "9.0.0"` only needs the workspace dep line plus re-hoisting `diff` top-level and the `astro/diff`/`shadcn/diff` nested entries — everything else reverts.

### Row-level cache over a shared bounded cache
- **Where**: `packages/web/src/lib/tool-presentation.ts` `fileDiffCache`/`fileDiffFor`
- **Pattern**: a module `WeakMap` keyed by the input record object makes "compute once per row" work when summary and body paths each call `asRecord(input)` (same reference); equal strings on fresh objects fall through to the inner dual-bounded LRU and return the identical result object. Verify "once" in tests with a counting getter on an own key.

### Gate/scope-resolution doc style
- **Where**: `_bmad-output/specs/spec-agent-node-room/SPEC.md` CAP-5, `_bmad-output/planning-artifacts/epics-agent-node-room/epics.md` Story 1.4 `_Scope:_` note
- **Pattern**: record scope resolutions as plain prose inside the owning section, citing `file:line` anchors (`codex/provider.ts:709`, `dag-executor.ts` `dag.system_message_unhandled`). No phase numbers, audit labels, or plan finding IDs in spec docs.
- **Example**: `Scope is presentation over persisted rows only: current Codex file_change events are emitted as system chunks (codex/provider.ts:709) ... never become persisted file rows`

### Pre-existing prettier failure in EXPERIENCE.md
- **Where**: `_bmad-output/planning-artifacts/ux-designs/ux-Archon-agent-node-room-2026-09-09/EXPERIENCE.md:115`
- **Pattern**: the `Body box: diff` table row was already unformatted at HEAD (prettier wanted different cell padding). `prettier --write` on the file is safe — the delta is confined to that one row, not a whole-file reformat.
