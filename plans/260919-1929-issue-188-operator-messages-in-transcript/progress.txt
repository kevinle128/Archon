## Codebase Patterns

### E2E starter identity header for browser sends
- **Where**: `e2e/ui/agent-queue-guidance.spec.ts`, `e2e/ui/agent-interrupt-redirect.spec.ts`
- **Pattern**: `page.setExtraHTTPHeaders({ 'X-Archon-User': E2E_STARTER_WEB_USER })` before room navigation so UI POSTs resolve `e2e-starter` projection. `startWorkflowViaWeb` already uses the starter; the default page does not.
- **Example**: `await page.setExtraHTTPHeaders({ 'X-Archon-User': E2E_STARTER_WEB_USER });`

### Attempt-scoped rooms drop prior-attempt tools
- **Where**: Console/Legacy node rooms load messages with `attemptId`
- **Pattern**: After redirect `Send now`, the live room switches to the resumed attempt and no longer mounts the interrupted attempt’s `[data-tool-id]`. Prove interrupted→operator adjacency via API `seq`; prove operator→echo with `compareDocumentPosition` on the live/fresh room.
- **Example**: `expect(interrupted!.seq).toBeLessThan(operatorRows[0]!.seq)`


### Operator receipt at first stream yield
- **Where**: `packages/workflows/src/dag-executor.ts` (`runStreamPass`, loop stream try)
- **Pattern**: Carry `readonly QueuedOperatorMessage[]` from drain/send_now; join prompt after `newTranscriptAttempt`; await `appendOperatorTranscript` on first stream chunk or normal empty completion of pass zero only; re-asks get no context.
- **Example**: `await recordOperatorReceiptIfNeeded()` before processing first `msg`

### Operator display-name projection stays local to api.ts
- **Where**: `packages/server/src/routes/api.ts` (`buildOperatorDisplayNameById`, `toWorkflowNodeMessageResponse`)
- **Pattern**: Collect operator text senders from the returned page only (cursor overflow excluded), one `getUserDisplayNamesByIds` call, attach trimmed name / 8-char fallback / explicit null; omit field on non-operator rows. Lookup rejection logs one payload-free warning and still returns 200.
- **Example**: `operator_display_name: resolveOperatorDisplayName(operatorSenderId(row), map)`

### Batch user display-name lookup
- **Where**: `packages/core/src/db/users.ts:getUserDisplayNamesByIds`
- **Pattern**: Dedupe with Set, empty → no query, sequential chunks of 500, positional `IN ($1…)` only.
- **Example**: `SELECT id, display_name FROM remote_agent_users WHERE id IN (${placeholders})`


### Operator history item is plain text, not assistant
- **Where**: `packages/web/src/lib/agent-history.ts` (`buildAgentHistory`)
- **Pattern**: Branch on `kind === 'text' && metadata?.origin === 'operator'` after tool cards and before generic text. Verbatim payload text; display name = trimmed response field else 8-char sender id else null; `delivery: 'sent'` literal. Never `presentedText` / Markdown / todo fold.
- **Example**: `items.push({ kind: 'operator', text: message.payload.text, delivery: 'sent', ... })`

### Local OperatorHistory on both shells
- **Where**: `NodeRoom.tsx`, `ConsoleAgentHistoryList.tsx`
- **Pattern**: Thin duplicate DOM (no shared component). Role line lowercase + CSS uppercase; body plain `{item.text}`; assistant corrected to 12.5px/1.55 text-secondary. `historyItemRowVisible` already shows non-tool/lifecycle kinds — do not special-case operator.
- **Example**: `<div data-operator-body ...>{item.text}</div>`
