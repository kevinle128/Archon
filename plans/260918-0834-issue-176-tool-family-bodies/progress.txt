## Codebase Patterns

### Bounded channel production in lib/ normalizers
- Where: `packages/web/src/lib/tool-output.ts`
- Pattern: normalize into a `TextAcc` (parts + unit count + truncated flag) with a single global budget; `sanitizeBounded` strips ANSI CSI/OSC/escapes/control chars inline while copying — never build an unbounded intermediate then slice. List channels go through `boundList(source, map, {trustedTotal, upstreamTruncated, flat})` which yields `omitted` as an exact positive int only when the total is trusted or a clean flat prefix was scanned, else `omitted: null` + `truncated: true`.
- Example: `pushText(acc, raw)` appends `\n`-separated sources inside `MAX_OUTPUT_TEXT_CODE_UNITS`; `boundList(filenames, e => toOne(stringListItem(e)), {flat: true})`.

### Hostile-input reads
- Where: `packages/web/src/lib/tool-output.ts` (`safeGet`, `ownKeys`, `applyRecord`'s `get` closure)
- Pattern: all property access on `unknown` records goes through try/catch readers; a throwing getter/proxy flags `accessError` so the result reports `unreadable` instead of fabricating empty channels. `for..in` + `hasOwnProperty` for own enumerable keys; never scan prototypes; never stringify unknown objects.

### Literal control characters in test/source files
- Where: `packages/web/src/lib/tool-output.test.ts`, `tool-output.ts` (`REPLACEMENT_CHAR`)
- Pattern: literal ESC/BEL/U+FFFD bytes embedded via the write tool survive but are invisible and can be silently dropped on rewrite — always spell them as `'\u001b'`/`'\u0007'`/`'\uFFFD'` escapes so the file is reviewable and robust.
