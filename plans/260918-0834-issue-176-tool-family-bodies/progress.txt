## Codebase Patterns

### Read-only DB access without @archon/core adapters
- Where: `scripts/audit-generic-fallback.ts`
- Pattern: DB adapters are unsafe for read-only tooling — `SqliteAdapter`'s constructor enables WAL + applies schema (writes). SQLite: `new Database(path, { readonly: true })` + `PRAGMA query_only = ON` inside one deferred txn. PostgreSQL: direct `Bun.sql` client + `sql.begin` + `SET TRANSACTION ISOLATION LEVEL REPEATABLE READ, READ ONLY`; never PostgresAdapter or `pg`. Pass the PG URL via an env-var NAME flag (`--postgres-env VAR`) so credentials stay off argv.
- Gotcha: `readonly: true` cannot open a *cleanly checkpointed* WAL db (no `-shm` to attach); live WAL (`-shm`/`-wal` present) and rollback-mode dbs open fine. Catch the open error and guide — never fall back to `immutable=1` (ignores WAL sidecars) or a write-capable handle.

### SQLite `->`/`jsonb ->` JSON projection asymmetry
- Where: `scripts/audit-generic-fallback.ts` (`SQLITE_PAGE_SELECT`, `PG_PAGE_SELECT`)
- Pattern: SQLite `payload -> '$.k'` returns JSON text only for composites — scalars come back as SQL values (string/number), which makes "is this JSON text" unverifiable. Re-wrap by type: `CASE json_type(payload,'$.k') WHEN 'object'|'array' THEN payload->'$.k' WHEN 'text' THEN json_quote(payload->>'$.k') WHEN 'integer'|'real' THEN CAST(... AS TEXT) WHEN 'true'|'false'|'null' THEN literal END`. PostgreSQL `(payload -> 'k')::text` renders every jsonb type as JSON text natively. Key presence = `json_type(...) IS NOT NULL` / `jsonb_exists(...)`.

### Streaming tally over keyset pages
- Where: `scripts/audit-generic-fallback.ts` (`ToolCardTally`)
- Pattern: when correlated rows (call/result) must be grouped before processing, page by `(run, node, seq, id)` keyset and buffer only the current group — flush on the group boundary, fail closed if the stream revisits a completed group (out-of-order = broken pager) or exceeds a per-group ceiling. Both sync (sqlite) and async (pg) drivers push rows into the same accumulator; never materialize the corpus.

### Import-safe CLI scripts
- Pattern: all parsing/connection/output/writes inside `main()`, gated by `if (import.meta.main) { process.exit(await main(process.argv.slice(2))) }`. Prove it with a child-process test: `bun -e "await import('...')"` in a scrubbed-env empty cwd must emit nothing and create nothing.

### Porting markup-regex tests to happy-dom
- Where: `packages/web/src/experiments/console/components/ConsoleNodeRoom.test.tsx`
- Pattern: happy-dom `innerHTML` does NOT escape `"`/`'` inside text nodes — Legacy assertions like `not.toContain('" onload="')` or `toContain('onload=&quot;')` fail under DOM mounting. Assert DOM facts instead: `el.getAttribute('onload')` null-sweeps over `querySelectorAll('*')`, `querySelector('a'/'img'/'script'/'b')` null checks, and `code[class*="language-"]` absence for hostile language values.
- Example: `for (const el of Array.from(row.querySelectorAll('*'))) expect(el.getAttribute('onload')).toBeNull();`

### Console isolation allowlist edits
- Where: `packages/web/src/experiments/console/console-isolation.test.ts`
- Pattern: the approved shared-module `Set` is the gate for `@/lib/*` imports into Console room files. Adding a module requires the concrete need documented inline next to the entry; `@/lib/tool-output` was added for `sanitizeBounded` (sent-name bar fallback) because `tool-presentation` does not re-export it.

### Asserting lazy resolver calls (spyOn ESM namespace)
- Where: `packages/web/src/components/workflows/LegacyNodeRoom.test.tsx`
- Pattern: `import * as ns from '@/lib/tool-presentation'` + `spyOn(ns, 'toolBodyPresentation')` DOES intercept calls made from inside NodeRoom.tsx under Bun (verified) — `mock.module()` is unnecessary and would pollute the process. Pair with `useMemo` keyed on the input's field values in the component so `calls + 1` is the exact post-load count (unrelated renders like the loading flag don't re-normalize).
- Example: `const spy = spyOn(toolPresentation, 'toolBodyPresentation'); …; expect(spy.mock.calls.at(-1)?.[0]).toEqual({name, input, output})`

### Element lookup in component tests (eslint dual rule)
- Where: `packages/web/src/components/workflows/LegacyNodeRoom.test.tsx` (`rowButton`, `rawButton`, `rowSummary`)
- Pattern: `non-nullable-type-assertion-style` forbids `as T` to strip null AND `no-non-null-assertion` forbids `!` — the sanctioned form is a helper that throws on null then returns `as unknown as T` (double assertion escapes both rules).

### Commit message bodies with special chars
- Pattern: `git commit -m "$(cat <<'EOF' … EOF)"` fails with "bad substitution: no closing `)'" when the body contains `(`/`)` — write the message to a temp file and use `git commit -F`. lint-staged (eslint --fix + prettier --write) runs on staged files and may modify them; tests stayed green.

### Lazy body layer (US-002)
- Where: `packages/web/src/lib/tool-presentation.ts` (toolBodyPresentation, ToolBody)
- Pattern: expanded bodies resolve lazily via `toolBodyPresentation(input, resolvedFamily)` — the caller's already-resolved family is authoritative and output never reclassifies it. Renderers (US-003/US-004) call it only while a row is open with Raw closed; summary paths must stay free of `normalizeToolOutput`. `todo`/`task` return null pending Stories 1.5/1.6.
- Example: `const body = row.open && !rawOpen ? toolBodyPresentation(item, row.family) : null`

### Bounded channel production in lib/ normalizers
- Where: `packages/web/src/lib/tool-output.ts`
- Pattern: normalize into a `TextAcc` (parts + unit count + truncated flag) with a single global budget; `sanitizeBounded` strips ANSI CSI/OSC/escapes/control chars inline while copying — never build an unbounded intermediate then slice. List channels go through `boundList(source, map, {trustedTotal, upstreamTruncated, flat})` which yields `omitted` as an exact positive int only when the total is trusted or a clean flat prefix was scanned, else `omitted: null` + `truncated: true`.
- Example: `pushText(acc, raw)` appends `\n`-separated sources inside `MAX_OUTPUT_TEXT_CODE_UNITS`; `boundList(filenames, e => toOne(stringListItem(e)), {flat: true})`.

### Hostile-input reads
- Where: `packages/web/src/lib/tool-output.ts` (`safeGet`, `ownKeys`, `applyRecord`'s `get` closure)
- Pattern: all property access on `unknown` records goes through try/catch readers; a throwing getter/proxy flags `accessError` so the result reports `unreadable` instead of fabricating empty channels. `for..in` + `hasOwnProperty` for own enumerable keys; never scan prototypes; never stringify unknown objects.

### Literal control characters in test/source files
- Where: `packages/web/src/lib/tool-output.test.ts`, `tool-output.ts` (`REPLACEMENT_CHAR`)
- Pattern: literal ESC/BEL/U+FFFD bytes embedded via the write tool survive but are invisible and can be silently dropped on rewrite — always spell them as `'\u001b'`/`'\u0007'`/`'\uFFFD'` escapes so the file is reviewable and robust.
