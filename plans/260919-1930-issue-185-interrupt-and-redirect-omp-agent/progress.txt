## Codebase Patterns

### OMP interrupt spike hygiene
- **Where**: `packages/providers/src/community/omp/interrupt-resume-spike.ts`, mirrors `packages/providers/src/claude/interrupt-resume-spike.ts`
- **Pattern**: Diagnostic spikes are not package-exported; script entry via `packages/providers/package.json` only. Spawn via `resolveOmpBinaryPath` + unique `mkdtemp` git cwd. Track owned PIDs only; reap in `finally`; never `pkill`. stdout is one sanitized JSON document (event types, timings, hashed ids) — no prompts, model text, credentials, or raw session ids.
- **Example**: `bun run spike:interrupt:omp` from `packages/providers`

### OMP SIGTERM mid-turn facts (darwin / 18.1.21)
- **Where**: `plans/reports/omp-interrupt-resume-spike.md`
- **Pattern**: `session` is first. Assistant Stop triggers on first `text_delta`; tool Stop on `tool_execution_start`. SIGTERM exits in ~100–140 ms with code 143; SIGKILL not required. No `agent_end` / usage `message_end` after signal — provider must synthesize interrupted result and drain buffered text. Open tools may get only `tool_execution_update` (no end). linux/win32 still uncharacterized.
- **Example**: raw leg exit 0 with `interruptCapability: false`
