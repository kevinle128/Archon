## Codebase Patterns


### OMP session flush vs mid-text SIGTERM
- **Where**: `plans/reports/omp-interrupt-resume-spike.md`, spike conformance leg
- **Pattern**: Brand-new OMP session interrupted mid-first-assistant-message emits `session` id but does not flush the session file — `--resume` fails. Seed one short completed turn before the long interruptible generation; prove context via seeded token boolean challenge. Capability flip still requires all advertised platforms or an owner-scoped decision.
- **Example**: `thisPlatformPass: true` + `capabilityFlipAllowed: false` when only darwin is characterized

### OMP stream-abort termination ownership
- **Where**: `packages/providers/src/community/omp/provider.ts`, `event-parser.ts`
- **Pattern**: Single terminate path with first-writer-wins cause (`interrupt|interrupt-unresumable|cancel|transport|protocol|cleanup`); pending Stop waits ≤500ms for session header then SIGTERM; parser `beginOperatorInterrupt` snapshots open tools; graceful interrupt yields drained assistant + one `terminalReason: stream_aborted` result (no throw); SIGKILL → unmarked `omp_interrupt_force_killed`.
- **Example**: `setTerminationGraceMsForTest(20)` for force-kill unit tests without a second real 5s wait

### OMP interrupt spike hygiene
- **Where**: `packages/providers/src/community/omp/interrupt-resume-spike.ts`, mirrors `packages/providers/src/claude/interrupt-resume-spike.ts`
- **Pattern**: Diagnostic spikes are not package-exported; script entry via `packages/providers/package.json` only. Spawn via `resolveOmpBinaryPath` + unique `mkdtemp` git cwd. Track owned PIDs only; reap in `finally`; never `pkill`. stdout is one sanitized JSON document (event types, timings, hashed ids) — no prompts, model text, credentials, or raw session ids.
- **Example**: `bun run spike:interrupt:omp` from `packages/providers`

### OMP SIGTERM mid-turn facts (darwin / 18.1.21)
- **Where**: `plans/reports/omp-interrupt-resume-spike.md`
- **Pattern**: `session` is first. Assistant Stop triggers on first `text_delta`; tool Stop on `tool_execution_start`. SIGTERM exits in ~100–140 ms with code 143; SIGKILL not required. No `agent_end` / usage `message_end` after signal — provider must synthesize interrupted result and drain buffered text. Open tools may get only `tool_execution_update` (no end). linux/win32 still uncharacterized.
- **Example**: raw leg exit 0 with `interruptCapability: false`
