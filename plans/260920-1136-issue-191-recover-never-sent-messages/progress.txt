## Codebase Patterns

### Ask resolution pre-resolution filter
- **Where**: `packages/server/src/routes/workflow-execution-history.ts` (`isPreResolutionStart`, owner finders)
- **Pattern**: Answered Ask closure only considers starts with `sortedIndex < resolvedEventIndex` so later resume starts do not create multi-candidate ambiguity; purge has no before-index filter.
- **Example**: Two open `type:'loop'` containers → without the filter, outer owner stays open; with it, only the parked outer fails.

### Observed ledger append-if-new
- **Where**: `packages/web/src/lib/steering-dock.ts` (`appendObservedIfNew`)
- **Pattern**: Local helper keyed by `messageId`; returns the same array reference when nothing is new so React identity short-circuits stay intact.
- **Example**: `applyQueueSnapshot` appends snapshot rows to the ledger before replacing `sent`; empty later snapshots clear `sent` only.

### Finished mode gate
- **Where**: `steeringDockMode`
- **Pattern**: `'finished'` requires nonempty `neverSent` AND `nodeTerminal === true`. `live:false` still hides first. Null/empty `neverSent` leaves the prior visibility table unchanged.
- **Example**: Terminal-looking selected rows without `nodeTerminal` never select finished.

### Dock mode union coupling
- **Where**: `ComposerDock.tsx` / `ConsoleComposerDock.tsx` `controlsMounted`
- **Pattern**: Local mode parameter unions must track `SteeringDockMode` (import the shared type) or package type-check breaks when a new mode is added.

### Attempt generation + suppressPersist on key reset
- **Where**: `ComposerDock.tsx` / `ConsoleComposerDock.tsx` layout reset effect
- **Pattern**: Bump `attemptGenerationRef` on non-null key replacement (and scope change); capture gen at async start; ignore continuations when gen drifts. On reset, `suppressPersistRef` skips one ordinary save after writing `{ draft, pendingRetry: null }`.
- **Example**: Queue/Send-now/withdraw/interrupt/poll onSnapshot all gate on `attemptGenerationRef.current === attemptGen`.
