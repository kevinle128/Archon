## Codebase Patterns

### Room-region band order
- **Where**: `NodeTranscriptPane.tsx`, `ConsoleNodeRoom.tsx`
- **Pattern**: Room-region direct children are scroller → optional controls → optional todo → dock. Dock is a fragment, so queue section + composer well are separate region children with queue first. Identify bands by roles/labels/testids (`node-transcript-scroll` / `console-node-room-scroll`, `section[aria-label="Todo"]`, `aria-label^="Queued messages"`, textarea parent). Scope navigator queries to the room region — Console header has its own Execution `<select>`.
- **Example**: `{scroller}{controls}{todos.length > 0 ? <TodoStrip .../> : null}<ComposerDock .../>`

### Fixed Node Room outer width
- **Where**: `packages/web/src/lib/room-split-layout.ts`, split owners
- **Pattern**: `ROOM_WIDTH_PX` is the only geometry contract. Split owners use a horizontal flex row: main `min-w-0 flex-1`, room `shrink-0` + inline `width: ${ROOM_WIDTH_PX.*}px` + `border-l border-border`. Single mode: main uses mutually exclusive `hidden` vs `flex` classes (not HTML hidden attr); room drops fixed width and uses `min-w-0 flex-1 w-full`.
- **Example**: `style={mode === 'split' ? { width: \`${ROOM_WIDTH_PX.legacy}px\`, overflow: 'hidden' } : { overflow: 'hidden' }}`

### Stale ratio keys
- **Where**: owner tests + `room-split-layout.test.ts`
- **Pattern**: Old `archon.run-room.ratio.*` localStorage values remain unread/unwritten. Deliberate test fixtures are the only production-tree mentions of those keys.


### E2E fixed outer room width
- **Where**: `e2e/ui/*` geometry helpers
- **Pattern**: Measure `#console-run-room` / `#legacy-run-room` at 520/460 ±1 in split mode. Never write `archon.run-room.ratio.*`. Strip width is relative to the inner room region (Console 4px outset when todo shown). Band order: assert DOM sibling order when margins can overlap boxes. Live todo+queue proof uses `e2e-room-anatomy` + `startWorkflowViaWeb`.
- **Example**: `expect(Math.abs(outerWidth - ROOM_WIDTH_PX[surface])).toBeLessThanOrEqual(1)`

### US-004 gate ladder
- **Where**: `packages/web` test script splits + `e2e` focused Playwright
- **Pattern**: Run narrow lib tests, then Radix-preloaded component regressions (include LegacyNodeRoom), then isolated Console invocation, then `bun --filter @archon/web test`, dual type-checks, then the nine focused Playwright specs. Never `bun test` from monorepo root. Sibling wrappers (LegacyNodeRoom) may still pin obsolete band order after room-body flips — flip those assertions in the gate story, do not weaken AC.
- **Example**: `NODE_ENV=development bun test --preload ./src/test/preload-radix-dom.ts src/components/workflows/LegacyNodeRoom.test.tsx`
