## Codebase Patterns

### MessageChunk textMode → transcript metadata.text_mode
- Where: `packages/providers/src/provider-types.ts` (MessageChunk.textMode?: 'complete' | 'delta' | 'snapshot'); persistence forwarding in `packages/workflows/src/dag-executor.ts` — `...(msg.textMode !== undefined ? { text_mode: msg.textMode } : {})` in BOTH the direct-node and loop-node transcript paths.
- Pattern: Providers declare the text boundary semantic on the chunk; the executor forwards it into row metadata verbatim. No DB/schema change needed — `metadata` is a free-form JSON column validated by `packages/workflows/src/schemas/node-execution.ts`.
- Example: `return [{ type: 'assistant', content: update.content.text, textMode: 'delta' }];`

### Transcript execution scope / attempt rotation
- Where: `packages/workflows/src/transcript-execution-scope.ts` — `newTranscriptAttempt(scope)` returns `{ ...scope, attempt_id: randomUUID() }` (same occurrence_id, new attempt).
- Pattern: Every provider re-ask inside a loop MUST rotate the scope before the next pass, or failed + repaired text land in the same attempt. The invalid-structured-output branch already did this (~dag-executor.ts:6630); the missing-output branch (~6660) previously only bumped `reaskAttempt` — now it rotates too.
- Example: `reaskAttempt++; iterationExecutionScope = newTranscriptAttempt(iterationExecutionScope); reaskErrors = ['no JSON object was found in the response']; continue attempts;`

### Executor test infra for transcript rows
- Where: `packages/workflows/src/dag-executor.test.ts` — `runNodes()` helper + fake transcript store capture; `runNodes` accepts an optional provider name (added `provider` param this iteration) so node `provider:` fields resolve through `workflowProvider`.
- Pattern: Assert on captured append payloads: `textRows[i].payload` for text, `textRows[i].metadata.execution` for `{ occurrence_id, attempt_id, retry_epoch, text_mode }`.
- Gotcha: `bun test -t` filters run fast; the full file is ~48s/629 tests. Test files are in the repo eslintignore — lint only production files when checking warnings.

### ACP bridge test fakes
- Where: `packages/providers/src/community/{devin,deepseek}/acp-client.test.ts`
- Pattern: Fake ACP child processes emit session/update JSON-RPC notifications; to test split streaming, emit two `agent_message_chunk` notifications ('Hel' then 'lo') before the terminal result and assert two ordered delta chunks.
