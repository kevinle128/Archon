## Codebase Patterns

### Registry msg() helper operator attribution
- **Where**: `packages/workflows/src/steering-registry.test.ts` `msg()`
- **Pattern**: Third optional arg `operatorUserId: string | null = 'user-1'` keeps existing call sites unchanged while mixed-sender tests pass distinct op-a/op-b ids.
- **Example**: `msg('a1', 'from-a-1', 'op-a')`

### Accept-order is the sole ordering oracle
- **Where**: `NodeSteeringHandle.accept()` / `drain()` / idle `send_now` batch
- **Pattern**: Snapshot and drain preserve synchronous accept() array order; first non-blank `send_now` while idle drains the whole pending batch in that order. No timers or timestamps for ordering truth.

### Route identity-gate interleaving
- **Where**: `packages/server/src/routes/api.workflow-runs.test.ts` overlapping identity streams test
- **Pattern**: Temporary `mockFindOrCreateUserByPlatformIdentity` keyed by header value; resolve `aEntered` then `await releaseA` for op-a only. Restores default identity mock in `finally`. Proves B accept() while A is pre-accept without timers or registry spies.
- **Example**: `if (platformUserId === 'op-a') { markAEntered(); await aHeld; }`

### Executor optional operator id on interrupt helpers
- **Where**: `packages/workflows/src/dag-executor.test.ts` interrupt suite `steeringMessage`/`enqueue`/`sendNow`
- **Pattern**: Optional 5th arg `operatorUserId: string | null = 'op-1'` (and matching 3rd arg on `steeringMessage`) keeps existing single-sender call sites while mixed-sender drain paths pass distinct ids. Direct #181 suite already had the same shape on `enqueue`.
- **Example**: `enqueue(RUN_ID, 'review', 'm-old-1', 'old note one', 'op-a'); sendNow(RUN_ID, 'review', 'm-new', 'new instruction', 'op-b')`

### E2E concurrent dock rounds + queueOrder oracle
- **Where**: `e2e/ui/agent-queue-convergence.spec.ts` `steer.concurrent-operators-*`
- **Pattern**: Pre-fill both docks, register per-page `waitForResponse`, press both `Meta+Enter` inside one `Promise.all`; after both round-1 responses, repeat for round 2. Snapshot server queue immediately as `queueOrder` (do not prescribe A/B winners). Transcript + DOM must equal that order; sibling node gets one explicit-UUID API send as isolation control.
- **Example**: `await Promise.all([starterField.press('Meta+Enter'), teammateField.press('Meta+Enter')])`
