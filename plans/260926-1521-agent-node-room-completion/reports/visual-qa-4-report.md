## Method

- **Isolated server.** The DB was copied with `sqlite3 ~/.archon/archon.db ".backup …"`. `config.yaml` and `credential-key` were copied into a scratch `ARCHON_HOME`. The only config change was `assistants.claude.advisorModel: opus`, made before the first boot. The server ran on 3337 with the env line from the brief, and Vite ran on 5205. Startup cleanup reported `removed: 0`, so no real worktree was touched.
- **Scratch repo.** A scratch git repo with a local bare `origin` was registered as codebase `c873d85b…`. Every run was dispatched over HTTP (`/api/conversations` → `/api/workflows/{name}/run`). Every `working_path` is under `scratchpad/vq4/home/workspaces/vq4/origin/worktrees/`, so no checkpoint or evidence ref reached this repository.
- **Workflows.** The round-3 set was reused under the `vq4-` prefix: `vq4-claude`, `vq4-loop`, `vq4-retry`, `vq4-grok`, `vq4-grok-structured`, `vq4-omp`, `vq4-deepseek`, `vq4-codex` and `vq4-deny`. Two workflows are new:
  - `vq4-codex-edit`: a Codex `apply_patch` edit, for Story 4.1.
  - `vq4-loop-steer`: a Claude loop with two 30 s Bash steps per iteration, for the Steering Dock states on a loop node.
- **Providers.** Every run used a real subscription. No fake provider was used.
- **Capture.** One Playwright context (`playwright-core` from `/Users/dale/orca/Archon/e2e/node_modules`) at 1440×900 with `X-Archon-User: vq4-operator`. It had three tabs: Console, Legacy and mockup. App crops are the room panel with its header. The panels were measured at Console **520 px** (`[data-testid=console-inspect-room]`) and Legacy **460 px** (`[data-testid=legacy-node-room]`).
- **Mockups.** The `.dc.html` mtimes are still 2026-09-26 15:13. All mockup crops were **recaptured fresh** from `http://127.0.0.1:8791/`:
  - 8 sub-states × {prompt, loop} × {Console, Legacy}, in the `codex · queue only` transport, because no real provider reports soft injection;
  - full-page captures of both rooms, `Transcript States` and `Steering Dock States`.
- **Pairs.** `pair-*.png` puts the mockup on the left and the app on the right.
- **Timing.** Cross-tab timings and dispatch transients were sampled from the DOM every 30–100 ms.
- **Evidence.** Everything is in `plans/260926-1521-agent-node-room-completion/evidence/visual-qa-4/`.
