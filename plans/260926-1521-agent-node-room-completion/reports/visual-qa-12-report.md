## Method

- **Isolated servers.** New scratch dir `…/scratchpad/vq12-1790686704/`. Two homes, each with a DB copied through `sqlite3 ~/.archon/archon.db ".backup …"` plus `config.yaml` and `credential-key`. The only config change is `assistants.claude.advisorModel: opus`. Real server on **3365** (brief env line, no fake flag). Fake-provider server on **3366** (same env line plus `ARCHON_E2E_FAKE_PROVIDER=1`, own home). Vite on 5233 → 3365 and 5234 → 3366. Mockups served by me on **8794**. Startup cleanup reported `removed: 0` on every boot. The codebase is a new scratch git repo (`wrk/`) with a local bare `origin`, registered on both servers; every run was dispatched over HTTP.
- **Providers.** Real subscriptions: Claude sonnet and haiku, Codex gpt-5.5, OMP `xai-oauth/grok-4.5`, Grok ACP, Grok `--single` (`output_format`), DeepSeek `alibaba/deepseek-v4.1-flash`. Qoder, Pi, Copilot and OpenCode were skipped as instructed. The two 30-min idle runs used real Claude on 3366 (the fake flag only adds a provider; the idle timer stays at the production 30 min).
- **Capture.** Two Playwright drivers (1440×900, `X-Archon-User: vq12-operator`), one per server, each with one Console page and one Legacy page. Measured widths: Console **520 px**, Legacy **460 px**. All 32 mockup crops (8 sub-states × {prompt, loop} × {Console, Legacy}, `codex · queue only`) and the two static sheets were captured again.
- **Timing.** Same 40 ms in-page sampler as round 11 in both shells. New this round: a `requestAnimationFrame` watcher on **every** terminal transition (natural completion, Send-now completion, live Abandon, recovered-node Abandon). It logs every frame change of pill, recovery text, controls, textarea, band, status line and alert count. 30 ms focus watcher in the stopping shell.
- **Child-process reap.** Before each Abandon or Stop I captured the tree under **my** server PID and polled every captured PID every 250 ms for 25–31 s. For Grok `--single` I also read the PPID of every captured PID at +3 s and +8 s.
- **Pairs.** `pair-*.png` = mockup left, app right. Evidence in `evidence/visual-qa-12/`: screenshots, pairs, and `data/` (`timing-summary.json`, `*-abandon.json` with rAF frames, `fin-FIN*.json`, `f75-F75*.json`, `*-recab2.json`, `recab-cycle1`, `postrestart-cycle1.json`, `NAT*-term.json`, `G-term.json`, `LP-b*.json`, focus traces, reap files, `axe.json`, `idle-fail.log`, `I2-keystroke.json`).
