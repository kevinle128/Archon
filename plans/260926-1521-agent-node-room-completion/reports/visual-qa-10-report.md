## Method

- **Isolated server.** New scratch dir `…/scratchpad/vq10-1790656438/` (home in `home/`). The DB was copied with `sqlite3 ~/.archon/archon.db ".backup …"`. `config.yaml` and `credential-key` were copied. The only config change was `assistants.claude.advisorModel: opus`. Server on 3352 with the env line from the brief, Vite on 5220. Startup cleanup reported `removed: 0` on both boots. Codebase `8809c301…` is a scratch git repo with a local bare `origin`. All runs were dispatched over HTTP to this server.
- **Providers.** Real subscriptions: Claude sonnet and haiku, Codex gpt-5.5, OMP `xai-oauth/grok-4.5`, Grok ACP, Grok `--single` (`output_format`), DeepSeek `alibaba/deepseek-v4.1-flash`. Claude tools used the CPU busy-wait. The other providers used `sleep 25`, and Codex also used `sleep 90` for the VQ9-1 check.
- **Capture.** One Playwright context at 1440×900 with `X-Archon-User: vq10-operator`. Measured widths: Console **520 px**, Legacy **460 px**. All 32 mockup crops (8 sub-states × {prompt, loop} × {Console, Legacy}) were recaptured from `http://127.0.0.1:8791/` in `codex · queue only`, cropped to the mockup `aside`. The two static sheets were captured full-page.
- **Timing.** A 40 ms in-page sampler ran in both shells, and a `requestAnimationFrame` sampler ran in the sending shell. A 30 ms focus watcher ran as in round 9. For the recovered-node Abandon, a 40 ms pill/band sampler ran in four tabs at once: Console and Legacy tabs **opened before the `kill -9`** and never reloaded ("surviving"), plus Console and Legacy tabs opened after the restart ("fresh").
- **Child-process reap.** Before each Abandon or Stop, I captured the process tree under **my** server PID with `ps` and polled each captured PID every 250 ms for 25–30 s. For Codex and Grok `--single`, I also read the PPID of every captured PID at +3/+5 s and +8 s to find orphans reparented to PID 1.
- **Pairs.** `pair-*.png` shows the mockup on the left and the app on the right. All evidence is in `evidence/visual-qa-10/`. Raw figures are in `timing-summary.json` (cycles, abandons, reaps, recovered abandons, loop boundaries, keyboard focus, idle timers) and in `axe.json`.
