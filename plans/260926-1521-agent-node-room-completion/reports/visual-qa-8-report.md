## Method

- **Build.** HEAD contains the qa7-fixes merge (`47354651`: `cf6293a8` dock timing gaps, `4eb71a4c` observer/terminal/focus wiring, `7cd4b9ae` withdraw-only queue-poll kick, `9a88abdf` warning pill token, `51e6e3dc` selector cap test).
- **Isolated server.** New scratch home `…/scratchpad/vq8-1790620046/home`. The DB was copied with `sqlite3 ~/.archon/archon.db ".backup …"`, and `config.yaml` and `credential-key` were copied. The only config change was `assistants.claude.advisorModel: opus`, made before the first boot. Server on 3347 with the env line from the brief, Vite on 5215. Startup cleanup reported `removed: 0` on both boots. The codebase `a22eaeeb…` is a scratch git repo registered by absolute path, with a local bare `origin`. Every run was dispatched over HTTP to the same server.
- **Providers.** Real subscriptions only: Claude sonnet and haiku, Codex gpt-5.5, OMP `xai-oauth/grok-4.5`, Grok ACP, Grok `--single` (`output_format`), and DeepSeek `alibaba/deepseek-v4.1-flash`. Claude tool calls used the CPU busy-wait. The other providers used `sleep 25`.
- **Capture.** One Playwright context at 1440×900 with `X-Archon-User: vq8-operator`, with Console, Legacy and mockup tabs. Measured widths: Console **520 px**, Legacy **460 px**. All 32 mockup crops (8 sub-states × {prompt, loop} × {Console, Legacy}) were recaptured fresh from `http://127.0.0.1:8791/` in `codex · queue only` and cropped to the mockup `aside`. The two static sheets were captured full-page. Cold-load checks used new browser contexts with no input.
- **Timing.** An in-page sampler read both panels every 40 ms and recorded every change. It recorded the band heading, the dock buttons, the header pill, the tool rows, `document.activeElement`, and a count of a per-test "needle" (0 = the message is shown nowhere, ≥ 2 = duplicate). Latencies are measured from the resolve of the `send` / `interrupt` / `abandon` POST.
- **Withdraw probe (VQ7-1).** In the observer shell, an in-page `requestAnimationFrame` probe clicks the first `delete ·` control it finds. It is armed only after the other shell's Send-now POST resolves, optionally after a delay (60 / 250–300 ms), to land inside the observer's lag window. The server's `removed` flag for every click was read from `api.workflow_node_withdraw_completed`.
- **Focus.** A 30 ms in-page watcher marks each focused element and records, at every change, whether the previous element is still connected.
- **Pairs.** `pair-*.png` puts the mockup on the left and the app on the right. Everything is in `plans/260926-1521-agent-node-room-completion/evidence/visual-qa-8/`. The per-cycle raw figures are in `timing-summary.json`.
