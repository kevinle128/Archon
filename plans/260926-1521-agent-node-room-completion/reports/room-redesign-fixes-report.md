# Room redesign e2e fixes

## Root cause

All 20 failures are the `console` variant of specs that loop over `['console', 'legacy']`. Every `legacy` twin passed before any change (todo strip 5 of 5, interrupt and converge legacy, occurrence legacy aside, see below).

The Console shell was removed. Since `cdd79711`, `openRunDetail()` opens the classic run detail with `?node=`, so the `console` variant is now the deep-link entry into the same redesigned room. It still asserted Console-only testids and design values. The owner decision to remove the console stands (`tasks/todo.md`), so the Console DOM is not restored. The coordinator approved the plan: the `console` key stays so scenario ids stay stable, and it means the deep-link entry.

## Fixes

Product:

- `packages/web/src/components/workflows/WorkflowDagViewer.tsx`: `panActivationKeyCode={null}` so a focused tool row or card summary can be toggled with Space while the graph is mounted beside the room.

Tests (locator and surface-constant repoints; no legacy assertion touched):

- Constants: scroller `node-transcript-scroll`, panel `legacy-run-room`, reference width 460, focus offset `-2px`, running token `--accent-bright` for the `console` key in `agent-todo-strip`, `agent-interrupt-redirect`, `file-edit-diff`, `task-dispatch-body`, `occurrence-navigation`.
- Deep link then Logs tab before node-list clicks (`switchRoom`, todo-strip scope navigation, interrupt loop header check).
- `occurrence-navigation`: wide viewport 1150 → 1400 (sidebar).
- `verifier-visual`: `visual-config.json` pins refreshed, stale console pin and the `console` surface removed (the Console surface is compared against Console mockups of a UI that no longer exists; the visual runner binding in `features/run-ui.json` is recomputed from the new config; the legacy surface still runs all 6 states at both viewports).

## Concerns

1. The room falls back to the single-column layout (`Back` button, no side-by-side) when the run pane is under 60rem. With the 248px sidebar that is viewports under 1208px, where the pre-redesign threshold was 960px. This is a layout-tuning decision for the redesign owner; I did not change it.
2. A breakpoint crossing remounts the dock and loses an unsent local draft when the server copy was already cleared (the spec pins that clearing as current behaviour). Real users rarely resize across the breakpoint mid-draft, so I did not change it.
3. `agent-tool-row-visual.spec.ts:1013` (legacy) failed once in a 30-test batch (timeout waiting for the `inspect-file` node button) and passed 3 of 3 in isolation. It was not among the 20. Watch the full-suite result.
4. `.agents/skills/verify-archon/features/run-ui.json` and `coverage-gaps.json` still list `packages/web/src/experiments/console/` paths that no longer exist. Left alone (out of scope).
5. The isolated scratch server on 3445 and 5313 was not needed. The e2e fixture boots its own instance per worker with the fake provider, which is what the node-room states need.
