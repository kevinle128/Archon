- **Pre-fix data.** For the VQ6-1 "rows stored by earlier builds" decision, a second server (3345 / Vite 5213) was started on a copy of the round-6 DB. Its `isolation_environments` rows were deleted from the copy first, so its cleanup could not touch anything (`removed: 0`). Run `968c67b9` was then opened in both shells. - **Tool calls.** The Claude workflows used a CPU busy-wait (`end=$((SECONDS+25)); while …`). The other providers used `sleep 25`.
- **Providers.** Every run used a real subscription: Claude sonnet/haiku, Codex gpt-5.5, OMP `xai-oauth/grok-4.5`, Grok ACP, Grok `--single` (`output_format`), and DeepSeek `alibaba/deepseek-v4.1-flash`. No fake provider was used.
- **Capture.** One Playwright context at 1440×900 with `X-Archon-User: vq7-operator`, with Console, Legacy and mockup tabs. `boundingBox` measured Console **520 px** and Legacy **460 px**. The mockups are unchanged (mtime 2026-09-26 15:13). All 32 state crops (8 × {prompt, loop} × {Console, Legacy}) were recaptured fresh from `http://127.0.0.1:8791/` in the `codex · queue only` transport and cropped to the mockup `aside` (520 / 460 px). The focus-on-load checks (VQ7-3) used new browser contexts with no prior input.
- **Timing.** An in-page sampler read both panels every 40 ms and recorded every change. It recorded the tool rows, the band heading, the buttons, the header and a count of a per-test "needle" string. The needle count finds gaps (0) and duplicates (≥ 2) of an operator message. Latencies are measured from the resolve of the `send` / `interrupt` / `abandon` POST, unless the table says otherwise. The raw figures are in `timing-summary.json`.
- **Pairs.** `pair-*.png` puts the mockup on the left and the app on the right, unless the image labels say otherwise.
- **Evidence.** Everything is in `plans/260926-1521-agent-node-room-completion/evidence/visual-qa-7/`.
