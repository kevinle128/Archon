## Mockup-vs-contract drift (not app defects; the app follows the contract)

- Queue header: the Console/Legacy mockups show `QUEUED 2`. The app shows `QUEUED · 1`, which matches `EXPERIENCE.md:93,142` and `Steering Dock States` (`Queued · 2`). Evidence: `pair-console-s1-generating.png`.
- Queue item font: the mockup draws queue items in sans-serif and the app uses monospace. `DESIGN.md:652` says the band shares the todo strip's "item geometry", and the strip items are monospace, so the app follows the spine. Evidence: `pair-console-s1-generating.png`.
- The `saved to server · Auto-send on` suffix appears only when auto-send is enabled (`steering-dock.ts:358`). The fake provider has it off, so the app shows `saved to server`.
- Idle-after-interrupt: the app adds a second line, `no redirect ends this node after 30 min of inactivity · typing keeps it open` (Story 2.12, `STEERING_IDLE_AWAIT_DISCLOSURE`). The mockup s3 shows only the first line. Evidence: `pair-console-s3-idle.png`.
- 30-min failure: mockup `interrupted by operator, no redirect received · failed after 30-minute idle timeout`. App `node failed · interrupted with no redirect · none of this was sent`, which is the copy mandated by `EXPERIENCE.md:263`. Evidence: `pair-console-s7-failed.png`.
- Field hint `Cmd/Ctrl+Enter to send · saved for you` between the dock controls is not drawn in the mockups. It is required by `EXPERIENCE.md:96` and epics 7.2.
- Recovery pill: the Console mockup says `Recovery required` and the Legacy mockup says `Running`, so the two mockups disagree (see VQ-4).
- Legacy tab bar: mockup `Logs · Graph · Chat · Files changed`. App `Graph · Logs · Chat · Source Control · Files changed · Terminal`. The Files changed tab exists (`17fafebb`). The extra tabs and their order are pre-existing product tabs. Evidence: `app-legacy-files-changed-1440.png` vs `mock-legacy-loop-full.png`.

## e2e results from this run (spec staleness vs product)

- `todo strip geometry … 460px on console` fails with `measured room width 512 must land within 460±2`. At a 1440 viewport (`SPLIT_VIEWPORT`) the spec writes a split ratio to drive both shells' room region to `TARGET_ROOM_WIDTH = 460` (`agent-todo-strip.spec.ts:54,155-181`). Console now holds a fixed 520 px panel, and its region inside the padding measures 512, which is the approved Console width. This is not an overflow: document `scrollWidth` equals the viewport. **The spec target is stale for Console.**
- `todo strip geometry … on legacy` fails: it expects `border-bottom: 1px` on the strip container, and the app has `0px`. No visible mockup difference could be paired (the queue band carries its own top rule), so this is not logged as a finding. Evidence: `live-todo-strip-legacy-460-failed-assert.png`.
- `steer.idle-await-queued-legacy`: Legacy focus fallback lands on `body`. This reproduces phase-b-ui finding 6 (`live-expired-queued-legacy-focus-fail.png`). It is still open.
- `withdraw.drain-legacy`: timed out waiting for the send POST. The node had already completed (30 s fake delay; `live-withdraw-drain-legacy-timeout.png`), so there is no product conclusion.
- `hitl.tool-row-mockups`: an environment artifact of the scratch copy (the mockup path resolves relative to the copied root).
