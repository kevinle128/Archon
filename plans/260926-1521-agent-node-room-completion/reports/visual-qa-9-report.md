## Method

- **Isolated server.** New scratch home `…/scratchpad/vq9-1790636182/home`. The DB was copied with `sqlite3 ~/.archon/archon.db ".backup …"`, and `config.yaml` and `credential-key` were copied. The only config change was `assistants.claude.advisorModel: opus` before the first boot. Server on 3349 with the env line from the brief, Vite on 5217. Startup cleanup reported `removed: 0` on all three boots. The codebase `128b3b5d…` is a scratch git repo with a local bare `origin`. Every run was dispatched over HTTP to the same server.
- **Providers.** Real subscriptions only: Claude sonnet and haiku, Codex gpt-5.5, OMP `xai-oauth/grok-4.5`, Grok ACP, Grok `--single` (`output_format`), DeepSeek `alibaba/deepseek-v4.1-flash`. Claude tools used the CPU busy-wait. The other providers used `sleep 25`.
- **Capture.** One Playwright context at 1440×900 with `X-Archon-User: vq9-operator`, with Console, Legacy and mockup tabs. Measured widths: Console **520 px**, Legacy **460 px**. All 32 mockup crops (8 sub-states × {prompt, loop} × {Console, Legacy}) were recaptured this round from `http://127.0.0.1:8791/` in `codex · queue only`, cropped to the mockup `aside`. The two static sheets were captured full-page.
- **Timing.** A 40 ms in-page sampler in both shells recorded every change of band, dock buttons, pill, tool rows, `document.activeElement` and a per-test needle count. For VQ8-5 the sending shell also ran a `requestAnimationFrame` sampler from the Send-now click to the first `SENDING` frame, because a 40 ms sampler can miss a shorter blank.
- **Focus.** A 30 ms watcher marked each focused element and logged every change, with `isConnected` of the previous element.
- **Child-process reap.** Before each Abandon (and before three Stops), the process tree under **my** server PID was captured by walking `ps -axo pid,ppid,command` from that PID (never a global name filter). Each descendant PID was then polled every 250 ms for 25–28 s after the POST.
- **Pairs.** `pair-*.png` = mockup left, app right. Everything is in `plans/260926-1521-agent-node-room-completion/evidence/visual-qa-9/`. Raw figures are in `timing-summary.json` (cycles, abandons, reaps, focus traces, loop-boundary samples) and `axe.json`.
