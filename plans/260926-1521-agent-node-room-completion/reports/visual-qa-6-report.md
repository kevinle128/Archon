## Method

- **Build.** HEAD contains the qa5-fixes (`2f2745d0`, `5bb0b116`, `5eaf9d2d`, `9d466c6a`) and the silent-tool cancel fix (`93fcce2b`). Because the executor and the idle timer changed, the 10.3 idle-timeout criteria were re-run on a real clock. They were not carried over from round 5.
- **Isolated server.** A new scratch home `…/scratchpad/vq6-1790590408/home`. The DB was copied with `sqlite3 ~/.archon/archon.db ".backup …"`, and `config.yaml` and `credential-key` were copied. The only config change was `assistants.claude.advisorModel: opus`, made before the first boot. The server ran on 3342 with the env line from the brief, and Vite ran on 5210. Startup cleanup reported `removed: 0`. The codebase `a610d10a…` is a scratch git repo registered by absolute `path`, with a local bare `origin.git`. Every run was dispatched over HTTP to the same server process.
- **Tool calls.** The Claude workflows used a CPU busy-wait (`end=$((SECONDS+25)); while [ $SECONDS -lt $end ]; do :; done`). The first run confirmed that the literal command reached the tool. The other providers used `sleep 25`.
- **Providers.** Every run used a real subscription: Claude sonnet/haiku, Codex gpt-5.5, OMP `xai-oauth/grok-4.5`, Grok ACP, Grok `--single` (`output_format`), and DeepSeek `alibaba/deepseek-v4.1-flash`. No fake provider was used.
- **Capture.** One Playwright context at 1440×900 with `X-Archon-User: vq6-operator`, with three tabs: Console, Legacy and mockup. The panels measured Console **520 px** and Legacy **460 px**. The mockups are unchanged (mtime 2026-09-26 15:13). All 32 state crops (8 × {prompt, loop} × {Console, Legacy}) were recaptured fresh from `http://127.0.0.1:8791/` in the `codex · queue only` transport and cropped to the mockup `aside` (520 / 460 px).
- **Timing.** An in-page sampler read both panels every 40–50 ms, in the same browser, so both shells share one clock. Latencies are measured from the resolve of the `send` / `interrupt` / `abandon` POST, not from the click, unless the table says otherwise. The summary is in `timing-summary.json`.
- **Pairs.** `pair-*.png` puts the mockup on the left and the app on the right.
- **Evidence.** Everything is in `plans/260926-1521-agent-node-room-completion/evidence/visual-qa-6/`.
