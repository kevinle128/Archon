## Method

- **Isolated server.** The DB was copied with `sqlite3 ~/.archon/archon.db ".backup …"`, and `config.yaml` and `credential-key` were copied into a scratch `ARCHON_HOME`. The only config change was `assistants.claude.advisorModel: opus`, made before the first boot. The server ran on 3335 with the env line from the brief. Vite ran on 5203. Startup cleanup reported `removed: 0` on both boots, so no real worktree was touched.
- **Scratch repo.** A scratch git repo with a local bare `origin` was registered as codebase `58f3b128…`. Nine workflows were used:
  - `vq3-claude`: sonnet, thinking, advisor, `TaskCreate`, and five 24 s Bash steps. The steps use `for … sleep 6` loops so the Claude Code sleep guard does not block them.
  - `vq3-loop`: haiku, 3 iterations of about 30 s each.
  - `vq3-retry`: an edit node, then a loop that fails once through a `$STATE_DIR` marker.
  - `vq3-grok`: default ACP transport.
  - `vq3-grok-structured`: declares `output_format`, so it uses the `--single` fallback.
  - `vq3-omp`: `xai-oauth/grok-4.5`.
  - `vq3-deepseek`: `alibaba/deepseek-v4.1-flash`.
  - `vq3-codex`: `gpt-5.5`.
  - `vq3-deny`: a Claude Bash call that the sleep guard denies.
- **Providers.** Every run used a real subscription. No fake provider was used.
- **Capture.** One Playwright context (`playwright-core` from `/Users/dale/orca/Archon/e2e/node_modules`) at 1440×900 with `X-Archon-User: vq3-operator`. The crops are the room panel with its header: Console 520 px and Legacy 460 px, both measured. Neither document scrolls horizontally.
- **Mockups.** The `.dc.html` mtimes are 2026-09-26 15:13, so the mockups have not changed since rounds 1 and 2. The round-1 and round-2 `mock-*.png` crops were reused. `pair-*.png` puts the mockup on the left and the app on the right.
- **Evidence.** Everything is in `plans/260926-1521-agent-node-room-completion/evidence/visual-qa-3/`.

## Verified matches

- **The whole steering flow on a real Claude run, in both shells:** Queue in Console shows the numbered band in Legacy at once; Stop gives `WILL SEND · 1` and both disclosures; a **blank Send now** is enabled (`… · 1 message will send`) and delivers exactly the one queued item as the next turn, with no empty operator row; generating again; Q2 queued from Legacy drains at the natural turn end; both rows end `delivered`.
- **Live `Iteration 2 · running`** is selected on open in both shells, with `of 2 · max 4`. The live iteration shows the full dock; a finished iteration is read-only.
- **UI Retry flow (Legacy):** the `Retry` action shows the `Retry checkout` radios with `Current HEAD c567ec988d8b` and `Node checkpoint 9b405c0952c5`, pre-selected `current` because HEAD moved. `Retry node` reruns the loop, and header, selector and inline heading all agree on run 2. Console has no Retry control, and neither mockup draws one.
