## Story 7.5 — failed automatic dispatch (new behaviour)

**Induction.** The server ran with `ARCHON_E2E_FAKE_PROVIDER=1`. The node uses `provider: e2e-fake` with a 45 s interruptible first turn. Auto-send was turned on through `PUT …/auto-send`. The queued text contains an **unclosed `<<E2E_USAGE>>`** directive. When the first turn ends naturally, auto-send claims that item; the fake provider's directive parser throws a plain `Error` before the first chunk, on the established session. The server logged `dag.node_dispatch_failure_retryable`.
