## Codebase Patterns

### CDP AX/DOM queries must stay room-scoped on console
- **Where**: `e2e/ui/task-dispatch-body.spec.ts` (`cardAxEvidence`)
- **Pattern**: The console run-detail page renders the same `details[data-tool-id]` row twice — once in the execution-history pane, once inside the node room. A global `DOM.querySelector` (or unscoped AX-tree query) can hit the history copy whose subtree is ignored. Always anchor the selector at the room region: `[aria-label="<nodeId> room"] details[data-tool-id="…"]`. Legacy renders tool rows only inside the room, so scoping is a no-op there — do it anyway for symmetric evidence.
- **Example**: `` `[aria-label="${nodeId} room"] details[data-tool-id="${id}"] details[data-subtask-index="0"]` ``

### Measured evidence attachments for visual reports
- **Where**: `e2e/ui/task-dispatch-body.spec.ts` (`testInfo.attach('…-task-card-geometry.json')`)
- **Pattern**: Accumulate every asserted computed style / AX name / bar text into one object and attach it as JSON — the acceptance report then quotes real measured values instead of hand-transcribed ones. `testInfo.attach({body})` inlines base64 into `e2e/ui/reports/results.json`; extract with a tiny script into `reports/evidence/` for committed artifacts.

### npm commands in e2e/ need a clean env
- **Where**: `e2e/` (standalone npm package)
- **Pattern**: the shell inherits `npm_config_local_prefix`, `npm_package_json`, `npm_execpath`, etc. from the parent Archon server process — they point at ANOTHER checkout (`/Volumes/WD_BLACK/workspace/opensource/Archon`), so `npm ci`/`npm run` silently operate on that prefix ("up to date" while node_modules is empty). Prefix npm commands with `env -i HOME="$HOME" PATH="$PATH"`.
- **Example**: `cd e2e && env -i HOME="$HOME" PATH="$PATH" npm ci && env -i HOME="$HOME" PATH="$PATH" npm run typecheck`

### Validating an e2e workflow fixture by hand
- **Where**: `e2e/fixtures/workflows/*.yaml`
- **Pattern**: `parseWorkflow` (packages/workflows/src/loader.ts) checks the provider registry — bare `bun -e` has an EMPTY registry so even existing fixtures fail 'unknown provider e2e-fake'. Register first: `registerCommunityProviders()` from `@archon/providers` registry under `ARCHON_E2E_FAKE_PROVIDER=1`.
- **Example**: `ARCHON_E2E_FAKE_PROVIDER=1 bun -e "import {registerCommunityProviders} from './packages/providers/src/registry.ts'; registerCommunityProviders(); const {parseWorkflow}=await import('./packages/workflows/src/loader.ts'); ..."`


### Card chevron bound to its own details[open] (no React state)
- **Where**: `NodeRoom.tsx` `SubtaskCard`, `ConsoleAgentHistoryList.tsx` `SubtaskCard`
- **Pattern**: subtask cards are UNCONTROLLED `<details class="group/subtask">`; the chevron uses `group-open/subtask:rotate-90` so rotation follows the card's own `[open]` attribute — the outer row's React `open` state never rotates a closed card, and happy-dom/class assertions can verify binding by checking `group-open/subtask:rotate-90` present + no bare `rotate-90` class.
- **Example**: `<details data-subtask-index={i} className="group/subtask ...">` + `<span aria-hidden className="... group-open/subtask:rotate-90">▶</span>`

### Scope sanitization assertions to the readable body
- **Where**: task-dispatch body tests in `NodeRoom.test.tsx`, `ConsoleNodeRoom.test.tsx`
- **Pattern**: the temporary Input diagnostic dumps the raw payload verbatim via `formatToolIo` — a hostile `javascript:`/`onclick=` fixture legitimately appears inside the closed Input `<pre>`. Security assertions (`no javascript:`, `no <img`) must slice the row before `>Input<`, not cover the whole row.
- **Example**: `const body = row.slice(row.indexOf('</summary>'), row.indexOf('>Input<'))`

### react-markdown leaks `node="[object Object]"` through prop spread
- **Where**: `MARKDOWN_COMPONENTS` / `TASK_CONTEXT_COMPONENTS` in both renderers
- **Pattern**: component props include `node`; the established `{...props}` spread writes `node="[object Object]"` into DOM markup. Harmless noise, matches existing convention — do not add `node` to test assertions.

### Task-dispatch normalization contract (Story 1.6 / CAP-4)
- **Where**: `packages/web/src/lib/task-normalize.ts`, `packages/web/src/lib/tool-presentation.ts`
- **Pattern**: `normalizeTaskDispatch(input)` maps OMP `{context?, tasks:[{name,agent,task}]}` -> `mode:'batch'` and Claude `{description, prompt, subagent_type?}` -> `mode:'single'` into `NormalizedTaskDispatch`; null on any malformed/over-budget input (all-or-nothing, never partial/truncated). An own `tasks` key is the discriminator — malformed `tasks` never falls through to Claude. `context`/`subagent_type`: `undefined` = absent (ok), any other non-string = reject. Identifier bound applies to the TRIMMED name/agent; cumulative 256KiB budget sums UNTRIMMED lengths before allocating.
- **Example**: `body = { kind:'task', context, subtasks: TaskSubtaskCard[] }` where each card is `TaskSubtask + {excerpt: taskPromptExcerpt(prompt)}`

### tool-presentation body model
- **Where**: `packages/web/src/lib/tool-presentation.ts`
- **Pattern**: `ToolPresentation.body: ToolBody|null` + `bodyFacts: string[]`; `ToolRowPresentation.bodyBarText` = `[family, ...facts].join(' · ')` composed once in the core. Normalized task -> bodyFacts `['batch','N subtasks']`/`['single dispatch']` + `count` badge `'N subagent(s)'`; the bar skips the task `count` badge only (non-task count badges like `14 matches` stay). Malformed task -> `{kind:'generic', fields: genericBodyFields(record)}` (<= MAX_GENERIC_FACTS rows, `[n]`/`{…}` markers, never stringify, hostile enumeration -> `[]`). `taskHeadline()` is wrapped in try/catch INSIDE the task branch so a throwing getter falls back to the label while keeping the body.
- **Example**: `bodyBarText` for a batch row with duration: `task · batch · 2 subtasks · 1.5s`

### Renderer body contract (done in US-002)
- **Where**: `NodeRoom.tsx`, `ConsoleAgentHistoryList.tsx`
- **Pattern**: both renderers print `presentation.bodyBarText` verbatim (no local recomposition), then render `presentation.body` via local `TaskBody`/`GenericBody`/`SubtaskCard` copies per shell (Console isolation forbids shared components). Readable body sits between the bar and the temporary Input/Output disclosures (Story 1.2 Raw toggle NOT landed — `fc90c62c` not an ancestor; if it lands later, the body belongs in the non-Raw branch). Outer `<details>` keeps `event.target !== event.currentTarget` onToggle guard.
- **Example**: `{presentation.bodyBarText}` → `{body?.kind === 'task' ? <TaskBody …/> : null}` → `{body?.kind === 'generic' ? <GenericBody …/> : null}` → Input/Output `<details>`

### Repo conventions
- **Where**: `packages/web/package.json`, root `package.json`
- **Pattern**: tests use `bun:test` (`describe/expect/test`); `bun test src/lib/` is the lib gate; `bun run type-check` = `tsc --noEmit`; eslint ignores `*.test.ts`; prettier formats on commit via lint-staged (`eslint --fix --max-warnings 0` + `prettier --write`). Commit via `git commit -F file` — zsh chokes on `$(cat <<'EOF')` heredoc-in-substitution.
- **Example**: `cd packages/web && bun test src/lib/task-normalize.test.ts`
