## Codebase Patterns

### Idle-after-interrupt timer ownership
- **Where**: `packages/workflows/src/steering-registry.ts` (`NodeSteeringHandle`)
- **Pattern**: One private `setTimeout` field + module-local `1_800_000` ms constant. Arm in `enterIdle`, clear in `seal`/`send_now`/`expireIdle`. First-wins via clearing `idleWaiter` before resolve. `recordComposerActivity` only re-arms when live + idle + waiter present.
- **Example**: `terminateIdleAwait()` → `seal('node_finished')` so Cancel poll shares the same waiter as expiry.

### Executor idle expiry under fake timers
- **Where**: `packages/workflows/src/dag-executor.test.ts` (`idle-after-interrupt timeout`)
- **Pattern**: Keep setup on real timers; provider fixture calls `gate.arm()` → `jest.useFakeTimers()` immediately before the abort-marked result and resolves a promise. `awaitIdleFast` awaits that promise then spins with `advanceTimersByTime(0)` only (never `Bun.sleep`, never `runAllTimers`).
- **Example**: `const gate = createFakeArmGate(); … gate.arm(); yield abortResult; await awaitIdleFast(…, gate.armed); jest.advanceTimersByTime(1_800_000)`.

### raceIdleWake settles Cancel through the handle
- **Where**: `packages/workflows/src/dag-executor.ts` `raceIdleWake`
- **Pattern**: Pass the handle; on non-continuing status call `handle.terminateIdleAwait()` instead of resolving a separate race promise. Await only the handle waiter; stop the poll in `finally`.


### Keepalive route hot/cold classification
- **Where**: `packages/server/src/routes/api.ts` (`keepaliveWorkflowNodeRoute`)
- **Pattern**: Mirror queue-read: hot path = registry get + snapshot only (no event scan). closed→409, parked→422 (unlike queue-read which allows parked), live→candidate. Cold path projects events for 404/409/422. Final awaited run re-read + handle phase re-read before synchronous `recordComposerActivity()`. Pre-gate POST middleware for nested 401. Success is strict `{ success: true }` only — never `sub_state`.
- **Example**: Handle closes during final `getWorkflowRun` await → 409 and activity spy never called.


### Dock keepalive leading throttle
- **Where**: `ComposerDock.tsx` / `ConsoleComposerDock.tsx`
- **Pattern**: Injectable `keepalive` prop; refs for last-sent timestamp + epoch. Send immediately on first idle textarea focus/change; coalesce within 1000 ms; reopen throttle on rejection if epoch/scope still current; bump epoch on run/node scope change and idle entry. Never update React state from the response. Never attach to Send now or well onFocusCapture.
- **Example**: `maybeKeepalive()` gated on `agentMode === 'idle'`; rooms pass only `timeoutFailure={latestNodeFailedByIdleExpiry(events, nodeId)}`.
