## Codebase Patterns

### Dock poll effect samples generation via dockRef
- **Where**: `ComposerDock.tsx` / `ConsoleComposerDock.tsx`
- **Pattern**: `dockRef.current = dock` during render; poll effect deps are `runId,nodeId,readQueue,pollIntervalMs,pollingEnabled` only; `currentGeneration: () => dockRef.current.queueGeneration`; acceptance inside functional `setDock`.
- **Example**: `return startQueuePolling({ read: signal => readQueue(runId, nodeId, { signal }), currentGeneration: () => dockRef.current.queueGeneration, onSnapshot, intervalMs: pollIntervalMs })`

### Queue snapshot hot path trusts close-before-terminal
- **Where**: `packages/server/src/routes/api.ts` (readWorkflowNodeQueue handler)
- **Pattern**: Live/parked handle → one `getWorkflowRun` + `registry.get` + `handle.snapshot()`; never list events on the 200 path. Cold path only when handle absent: project events for 404/409/422. Comment cites dag-executor close-before-terminal (~3290-3568, ~5669-5674, ~6868-7119).
- **Example**: `const handle = getSteeringRegistry().get(runId, nodeId); if (handle) { const snapshot = handle.snapshot(); ... }`

### queueGeneration guards stale snapshot application
- **Where**: `packages/web/src/lib/steering-dock.ts`
- **Pattern**: Bump on every resolved send/withdraw (including idempotent replay and already-removed withdraw). `applyQueueSnapshot` returns identical object when `generationAtRequest !== state.queueGeneration`. Poller samples generation at request fire time.
- **Example**: `if (generationAtRequest !== state.queueGeneration) return state;`

### Method-guarded pre-gate for GET queue no-store + nested 401
- **Where**: `packages/server/src/routes/api.ts` middleware on `/api/workflows/runs/:runId/nodes/:nodeId/queue`
- **Pattern**: Set `Cache-Control: no-store` before success or early error; nested 401 when auth required and no identity; `next()` for non-GET so DELETE is untouched. Handler does not re-resolve requester.

### Dual-shell read helpers
- **Where**: `packages/web/src/lib/api.ts`, `packages/web/src/experiments/console/skills/runs.ts`
- **Pattern**: Both export `readNodeGuidanceQueue(runId, nodeId, { signal? })` with URL-encoded segments, GET + `cache: 'no-store'`, failures via `toSteeringSendError()`, no auto-retry. Console uses `requestJson` only — never imports `@/lib/api`.
